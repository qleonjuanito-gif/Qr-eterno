Backend PHP & MySQL para tu Hosting Propio

Implementa esta arquitectura en cPanel, Apache o Nginx para tener total independencia sin suscripciones mensuales.

r.php (Redireccionador Dinámico Ligero) 
<?php
// Script de Redirección Ultra-Rápido sin Expiración (r.php)
// Conexión a Base de Datos Propia
$db_host = "localhost";
$db_user = "tu_usuario";
$db_pass = "tu_password";
$db_name = "qreterno_db";

$conn = new mysqli($db_host, $db_user, $db_pass, $db_name);

if ($conn->connect_error) {
    die("Error de Conexión: " . $conn->connect_error);
}

// Obtener parámetro de ID único del QR
$code_id = isset($_GET['c']) ? $conn->real_escape_string($_GET['c']) : '';

if (!empty($code_id)) {
    // 1. Incrementar contador de escaneos
    $conn->query("UPDATE qr_codes SET scans = scans + 1 WHERE code_id = '{$code_id}'");
    
    // 2. Obtener URL o contenido de destino
    $result = $conn->query("SELECT target_url FROM qr_codes WHERE code_id = '{$code_id}' LIMIT 1");
    if ($row = $result->fetch_assoc()) {
        header("Location: " . $row['target_url'], true, 302);
        exit();
    }
}

// Redirección por defecto si el código no existe
header("Location: https://tudominio.com", true, 302);
exit();
?>
schema.sql (Estructura MySQL) 
CREATE TABLE IF NOT EXISTS `qr_codes` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `code_id` VARCHAR(50) NOT NULL UNIQUE,
  `type` VARCHAR(20) NOT NULL,
  `title` VARCHAR(150) NOT NULL,
  `target_url` TEXT NOT NULL,
  `scans` INT DEFAULT 0,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

Instrucciones de Instalación Rápida:

  1. Crea una base de datos MySQL en tu hosting e importa el archivo schema.sql.
  2. Sube el archivo r.php a la raíz de tu dominio (ej. https://tudominio.com/r.php).
  3. Los códigos QR impresos apuntarán a URLs cortas como https://tudominio.com/r.php?c=qr_m102.
